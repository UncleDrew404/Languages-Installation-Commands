## Introduction
Django is a free and open-source web framework for Python used to build web applications quickly, securely, and in an organized way. It provides many built-in features such as database management, user authentication, URL routing, forms, security protection, and an administrative dashboard.

## Installation and Setup

### Installation
If you don't have install Python on your local machine. the following commands will install Python (Windows, Linux, MacOS).

* **Windows**
```
python --version
py install
```
* **MacOS**
```
brew install python
```

* **Ubuntu/Debian Linux**
```
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

* **Arch Linux**
```
sudo pacman -S python python-pip
```

#### Installing Django

If you done install Python, you many now install the Django.

* **Creating Folder Project**
```
mkdir my-django-project
cd my-django-project
```

* **Create Virtual Environement**
```
python -m venv .venv
```

* **Activate Environment**
```
.\.venv\Scripts\Activate.ps1
```

* **Upgrade pip**
```
.\.venv\Scripts\Activate.ps1
```

* **Install Django**
```
python -m pip install django
```

* **Check Django Version**
```
python -m django --version
```

### Setup

* **Create Config**
```
python -m django startproject config . 
```

* **Create app**
```
python manage.py startapp app-name
```

## Cheatsheet

### Django Commands

#### Project & App 
| Command | Description |
|:---| :---| 
| `django-admin startproject config .` | Create a config in project |
| `python manage.py startapp appname` | Creates a new Django app inside the project. | 
| `python manage.py runserver` | Starts Django's local development server. | 
| `python manage.py runserver 8080` | Runs the development server on a custom port. | 
| `python manage.py runserver 0.0.0.0:8000` | Allows the development server to be accessed from other devices on the network. |

---

#### Migration
| Command | Description | 
|:--- | :--- |
| `python manage.py makemigrations` | Creates migration files based on changes made to models. | 
| `python manage.py makemigrations app_name` | Creates migrations only for a specific app. | 
| `python manage.py migrate` | Applies migrations to the database. | 
| `python manage.py showmigrations` | Displays all migrations and shows which ones have been applied. | 
| `python manage.py showmigrations app_name` | Displays migrations for a specific app. | 
| `python manage.py showmigrations --plan` | Shows the order Django will use when applying migrations. | 
| `python manage.py sqlmigrate app_name 0001` | Shows the SQL generated by a migration file. | 
| `python manage.py makemigrations --check --dry-run` | Checks if model changes require new migrations without creating files. |

---

#### Project Check
| Command | Description | 
|:--- | :--- |
| `python manage.py check` | Checks the Django project for configuration errors and common problems. |
| `python manage.py check app_name` | Checks a specific Django app. |
| `python manage.py check --deploy` | Performs additional checks related to production deployment and security. |
| `python manage.py check --tag models` | Checks problems related specifically to models. |

---

#### Testing
| Command | Description | 
|:--- | :--- |
| `python manage.py test` | Runs all automated tests in the project. |
| `python manage.py test app_name` | Runs tests only for a specific app. |
| `python manage.py test --verbosity=2` | Runs tests while displaying more detailed information. |
